\section{Introduction}
This report documents the development of an interactive To-Do List web application built using HTML, CSS, and JavaScript. The application follows a class-based MVC architecture and includes features such as localStorage persistence, task filtering and sorting, inline editing, and CSS transitions.

% --------------------------------------------------------
\section{Application Features}
\begin{itemize}
    \item \textbf{Task Class}: Each task is an instance of a \texttt{Task} class with \texttt{id}, \texttt{description}, \texttt{completed}, and \texttt{createdAt} properties.
    \item \textbf{Add / Delete / Toggle}: Users can add new tasks, delete existing ones, and toggle completion state.
    \item \textbf{Inline Editing}: Tasks can be renamed in-place.
    \item \textbf{Persistence}: Tasks are saved to and loaded from \texttt{localStorage}.
    \item \textbf{Filtering}: Filter buttons for All, Completed, and Incomplete tasks.
    \item \textbf{Sorting}: Sort tasks alphabetically (A--Z) or by creation time.
    \item \textbf{Timestamps}: Each task displays its creation date and time.
    \item \textbf{Icons}: Unicode icons are used for toggle, edit, and delete actions.
    \item \textbf{CSS Transitions}: Smooth slide-in animation for new tasks and fade-out for deleted tasks.
    \item \textbf{MVC Structure}: The app is organized into a \texttt{TaskManager} controller class that manages the model (task array) and view (DOM rendering).
\end{itemize}
